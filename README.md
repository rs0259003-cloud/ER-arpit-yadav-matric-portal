# ER ARPIT YADAV — MATRIC PORTAL (बिहार बोर्ड कक्षा 10वीं)

यह बिहार बोर्ड (BSEB) कक्षा 10वीं के विद्यार्थियों के लिए एक सम्पूर्ण, मोबाइल-फ्रेंडली ऑनलाइन मॉक टेस्ट वेब एप्लिकेशन है।

## 🚀 मुख्य विशेषताएँ (Features)
- **विषयवार मॉक टेस्ट**: विज्ञान, गणित, सामाजिक विज्ञान, हिंदी, संस्कृत और अंग्रेजी।
- **रियल-टाइम टाइमर (Countdown Timer)**: परीक्षा की सटीक तैयारी के लिए।
- **प्रश्न नेविगेटर palette**: Answered, Unanswered और Marked for Review स्थिति।
- **स्वचालित अंक और परिणाम**: तुरंत प्रतिशत, सही/गलत उत्तर का स्कोरकार्ड।
- **विस्तृत उत्तर एवं व्याख्या**: प्रत्येक प्रश्न का हिंदी में समाधान।
- **राज्यस्तरीय टॉपर्स लीडरबोर्ड**: छात्रों की रैंकिंग और स्कोर।
- **शिक्षक / एडमिन पोर्टल**: नए प्रश्न जोड़ने का विकल्प (Default PIN: 123456)।

## 🛠️ प्रोजेक्ट सेटअप और रन करने की विधि

### कंप्यूटर (PC / Laptop) पर:
1. zip फ़ाइल को एक्सट्रैक्ट (Unzip) करें।
2. टर्मिनल में प्रोजेक्ट फोल्डर के अंदर जाएं:
   ```bash
   cd er-arpit-yadav-matric-portal
   ```
3. आवश्यक पैकेज इनस्टॉल करें:
   ```bash
   npm install
   ```
4. डेवलपमेंट सर्वर चलाएं:
   ```bash
   npm run dev
   ```

### 📱 मोबाइल (Mobile) से मुफ्त में होस्ट करें:
1. इस प्रोजेक्ट की फ़ाइलों को **GitHub** पर अपलोड करें।
2. **Netlify.com** या **Vercel.com** पर अपने GitHub अकाउंट से लॉगिन करें।
3. अपनी रिपॉजिटरी कनेक्ट करें — आपकी वेबसाइट 1 मिनट में ऑनलाइन लाइव हो जाएगी!
